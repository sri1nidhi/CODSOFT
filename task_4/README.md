# Movie Recommendation System

## Objective
Create a recommendation system that suggests movies based on user preferences.

## Features
- Genre-based recommendations
- Simple and user-friendly interface
- Uses CSV dataset
- Content-Based Filtering

## Technologies Used
- Python
- Pandas

## How to Run

```bash
python recommendation_system.py
```

## Available Genres

- Action
- Sci-Fi
- Animation
- Romance
