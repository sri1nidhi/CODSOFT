# Image Captioning AI

## Objective

Develop an AI system that generates descriptive captions for images using a pre-trained deep learning model.

## Features

* Automatic image caption generation
* Uses BLIP Image Captioning Model
* Supports JPG, JPEG and PNG images
* Command-line interface

## Technologies Used

* Python
* Transformers
* PyTorch
* Pillow

## Installation

pip install transformers torch pillow

## Run

python image_captioning.py

## Example

Input:
dog.jpg

Output:
a dog running through a grassy field

## Applications

* Accessibility tools
* Image search systems
* Social media automation
* Content generation
