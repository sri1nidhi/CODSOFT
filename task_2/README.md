# Tic Tac Toe AI

## Objective
Implement an AI agent that plays the classic Tic-Tac-Toe game against a human player using the Minimax algorithm.

## Features
- Human vs AI
- Unbeatable AI using Minimax
- Console-based game
- Input validation
- Win/Draw detection

## Technologies Used
- Python
- Minimax Algorithm

## How to Run

```bash
python tictactoe.py
```

## Game Rules

- You play as X
- AI plays as O
- Enter positions from 1 to 9
- First player to align 3 symbols wins
